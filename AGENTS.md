# Working on Claim Atlas

Read docs/architecture.md for the implementation contract and docs/product.md for user requirements. The installable skill is skills/claim-atlas. Keep its instructions portable; tools are supplied by the host assistant.

Run `python tools/manage.py check` after changes. Run `python tools/manage.py build` when changing a distributed skill file. Public examples must be fictitious. No mailbox exports, personal reports or claim credentials belong in Git. Preserve user files and tracking state on upgrade. Do not add legal eligibility inference to offline utilities.
