# Cost and coverage

The skill is free source code. Your assistant/model/connectors may have usage limits or charges. No model prices are quoted here.

Public-first can take longer: each case needs official verification and historical mail queries. Notice-first usually reads fewer messages. Select the accounts/geography you want checked. Metadata triage, plain-text retrieval, deduplication and cached verification reduce repeated work without sampling away coverage.

A smaller agreed scope is valid; silently stopping at a fixed cap is not. Coverage disclosures distinguish inaccessible folders, blocked directories, incomplete pagination and unprocessed candidates. A generated query plan is not a completed scan.
